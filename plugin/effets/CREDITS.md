# Module d'effets : crédits

Le dossier `kit/` est le module « Studio » créé par **Justyn Berkovits**, sous licence MIT (texte complet dans `kit/LICENSE`).
Il est reçu par le plugin `editeur` de Théo Parisi (Project Orange), qui en offre les mises à jour à Etienne Bertani.

- `kit/` est intégré au Studio et adapté librement. `moteur/effets_veille.py` compare de temps en temps nos fichiers avec la dernière version offerte par Théo et dit ce qui peut être repris ; rien n'est jamais écrasé automatiquement.
- Version et commit de la copie : `SOURCE.json`.
- Les choix du Studio IA (styles, coupe, sous-titres, son, contrôles, livraison) restent dans le reste du plugin ;
  le module sert de couche d'effets (habillage, effets par nom, storyboard à commenter, Copie, nouvel effet, Trials).
